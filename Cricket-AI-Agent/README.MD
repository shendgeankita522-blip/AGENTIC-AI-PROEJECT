# 🏏 Cricket AI Agent

An AI-powered Cricket Agent built with Python and Generative AI. The agent can understand cricket-related queries and provide intelligent responses using an LLM and web search capabilities.

## 🚀 Features

* 🏏 Cricket-related question answering
* 🤖 AI-powered responses
* 🔎 Web search for information
* ⚡ Real-time information retrieval
* 🌐 Streamlit-based interface
* 🔐 API keys managed using environment v

## 🛠️ Technologies Used

* Python
* Google Gemini
* Phi
* DuckDuckGo Search
* Streamlit
* python-dotenv

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Agentic-AI-Projects.git
cd Agentic-AI-Projects/Cricket-AI-Agent
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## 🔑 API Configuration

Create a `.env` file inside the project folder.

Example:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Use `.env.example` as a reference.

⚠️ **Do not upload your actual API keys to GitHub.**

## ▶️ Run the Application

If using Streamlit:

```bash
streamlit run cricketapp.py
```

The application will open in your browser.

## 💡 Example Queries

You can ask questions such as:

```text
Who is the current captain of India?

What are the latest cricket matches?

Tell me about Virat Kohli's career.

What is the latest cricket news?
```
