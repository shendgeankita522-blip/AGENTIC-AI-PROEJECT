# ⚡ Groq AI Agent

An AI-powered agent built using **Python, Groq, and Phi**. This project demonstrates how an AI agent can use a Large Language Model (LLM) to understand user queries and generate intelligent responses.

## 🚀 Features

* 🤖 AI-powered conversational agent
* ⚡ Fast responses using Groq
* 🧠 Large Language Model integration
* 🔐 Secure API key management using environment variables
* 🐍 Python-based implementation
* 🔧 Easy to configure and run

## 🛠️ Technologies Used

* Python
* Groq
* Phi
* python-dotenv

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Agentic-AI-Projects.git
```

Navigate to the project folder:

```bash
cd Agentic-AI-Projects/Groq-AI-Agent
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## 🔑 API Configuration

Create a `.env` file inside the `Groq-AI-Agent` folder.

Add your Groq API key:

```env
GROQ_API_KEY=your_groq_api_key_here
```

You can use `.env.example` as a template.

⚠️ **Never upload your actual API key to GitHub.**

## ▶️ Run the Agent

Run the Python file:

```bash
python groqagent.py
```

If your project uses Streamlit, run:

```bash
streamlit run groqagent.py
```
